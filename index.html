Module 1: Deep Dive into Probability & Sets

Probability quantifies uncertainty on a scale from 0 (impossible) to 1 (certain). In Machine Learning, everything is probabilistic (e.g., "The model is 92% confident this image is a cat").

Axioms and Set Rules

An event E is a subset of the Sample Space S. The probability of an event happening is the number of favorable outcomes divided by total possible outcomes.

P(E) = |E| / |S|
0 ≤ P(E) ≤ 1
P(S) = 1 (Sum of all probabilities is 1)
  • Complement Rule: The probability of an event NOT happening.
    P(A') = 1 - P(A)
  • Mutually Exclusive: Events that cannot co-occur (e.g., rolling a 1 AND a 6 simultaneously on one die).
    P(A ∩ B) = 0
  • Independent Events: The outcome of A does not change the probability of B (e.g., two separate coin flips).
    P(A ∩ B) = P(A) × P(B)

The Addition Rule (Union)

Event A
Event B

To find the probability of A OR B, we add their individual probabilities but must subtract the overlap (Intersection) to avoid double-counting.

P(A ∪ B) = P(A) + P(B) - P(A ∩ B)

Module 2: Bayes' Theorem & Conditional Math

Conditional probability P(A|B) asks: "What is the probability of A, given the strict condition that B has already happened?" Bayes' Theorem allows us to reverse this question, which is the foundation of Naive Bayes classifiers.

The Complete Formulas

The basic conditional formula constrains the universe to only instances where B is true:

P(A|B) = P(A ∩ B) / P(B)

Bayes' Theorem expands on this using the Law of Total Probability to find the denominator P(B):

P(A|B) = [ P(B|A) × P(A) ] / P(B)

Expanded form:
P(A|B) = [P(B|A)P(A)] / [P(B|A)P(A) + P(B|A')P(A')]

Terminology Breakdown

  • Prior P(A): What we believed before seeing new evidence. (e.g., Historically, 20% of emails are spam).
  • Likelihood P(B|A): How likely the evidence is, assuming our hypothesis is true. (e.g., If it IS spam, there's a 90% chance the filter flags it).
  • Marginal / Evidence P(B): The total probability of observing the evidence under all circumstances.
  • Posterior P(A|B): Our updated belief. (e.g., The probability it is spam because it was flagged).

Module 3: Combinatorics & Counting

Combinatorics determines the size of sample spaces. If an algorithm tests every combination of 5 features out of 100, combinatorics tells us exactly how many computations that will require.

The Fundamental Counting Principle

If event 1 can occur in m ways, and event 2 can occur in n ways, then both events occurring in sequence can happen in m × n ways.

Permutations (Order Matters)

Selecting r objects from n total, where arrangement is critical (e.g., determining 1st, 2nd, and 3rd place in a race).

nPr = n! / (n-r)!

Total: 5040

Combinations (Order Ignored)

Selecting a subgroup r from n total, where arrangement means nothing (e.g., picking 4 features to train a model).

nCr = n! / [ r! × (n-r)! ]

Module 4: Descriptive Stats & Dispersion

Before applying complex ML models, we must understand the shape, center, and spread of our data. Central tendency defines the "typical" value, while dispersion measures how chaotic the data is.

Central Tendency

  • Mean (μ or x̄): Sum of all values divided by N. Formula: μ = Σxi / N. Highly sensitive to extreme values.
  • Median: The physical middle point of sorted data. Completely robust to outliers, making it superior for skewed data like salaries or house prices.
  • Mode: The most frequent value, mostly used for categorical variables.

Dispersion (Spread)

Variance squares differences to aggressively penalize large outliers and remove negative signs. Standard Deviation returns the metric to base units.

Population Variance: σ² = Σ(xi - μ)² / N
Sample Variance: s² = Σ(xi - x̄)² / (n - 1)

Standard Deviation: σ = √σ²

Note: Sample variance divides by n-1 (Bessel's correction) to provide an unbiased estimator of the population.

Module 5: The Normal Distribution

The Normal (Gaussian) Distribution is the most important continuous distribution in ML. It assumes that data clusters around a central mean, dropping off symmetrically.

Probability Density Function (PDF)

Unlike discrete points, continuous probabilities are found by calculating the area under the curve between two points using this function:

f(x) = (1 / σ√2π) × e-0.5((x-μ)/σ)²

Z-Scores: Converts any normal curve into the Standard Normal Distribution (μ=0, σ=1). Fundamental for ML feature scaling.

Z = (x - μ) / σ

Skewness & Asymmetry

  • Perfect Normal: Mean = Median = Mode. Symmetrical.
  • Positive (Right) Skew: Tail extends right. Extreme high values pull the Mean upwards.
    Mean > Median > Mode
  • Negative (Left) Skew: Tail extends left. Extreme low values pull the Mean downwards.
    Mean < Median < Mode

Module 6: Discrete Distributions (PMF)

Discrete random variables represent countable outcomes (e.g., number of fraudulent transactions). Instead of area under a curve, we use Probability Mass Functions (PMF) to map exact probabilities to integers.

Bernoulli Distribution

Models a single trial with only two possible outcomes: Success (p) or Failure (1-p). Think of a single coin toss.

Expected Value E[X] = p
Variance Var(X) = p(1 - p)

Binomial Distribution

Models the number of successes (r) in a fixed number of independent Bernoulli trials (n) with probability p.

P(X=r) = nCr × pr × (1-p)n-r

E[X] = n × p
Var(X) = n × p × (1 - p)

Module 7: Bivariate Statistics

Machine learning algorithms rely on understanding how different features relate to each other. Bivariate statistics analyze two variables simultaneously to find directional dependencies and linear strength.

Covariance

Measures the direction of a linear relationship. If positive, they move together; if negative, they move inversely. However, its raw value is scale-dependent, meaning it cannot tell you the strength.

Cov(X,Y) = Σ(xi - μx)(yi - μy) / N

Pearson Correlation (ρ)

Standardizes Covariance by dividing it by the product of both standard deviations. This forces the metric onto a strict scale from -1.0 to +1.0, allowing universal strength comparison.

ρ = Cov(X,Y) / (σx × σy)
